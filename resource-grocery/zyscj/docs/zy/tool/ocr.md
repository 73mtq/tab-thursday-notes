# 🔗OCR文字图片识别

> 来源：<https://zyscj.com/zy/tool/ocr.html>  ·  抓取时间：2026-11-01  ·  外链 19 个

> OCR是什么 ？ OCR （Optical Character Recognition，光学字符识别）是指电子设备检查纸上打印的字符，通过检测暗、亮的模式确定其形状，然后用字符识别方法将形状翻译成计算机文字的过程。
